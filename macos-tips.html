1必会快捷键（按使用频率排序）

先掌握下面这些，鼠标使用量能降到 30% 以下。粗体是 90% 用户没用过但极其高频的隐藏组合。

系统级

⌘+TabApp 切换（按住 ⌘ 不放，多按 Tab 选）

2Spotlight 进阶用法

Spotlight (⌘+Space) 不只是搜文件，它是一个万能命令面板。

单位换算
直接打 100 usd to cny、30 km in mi
计算器
输入 1024 * 768 / 60 立即得结果
天气/股票
weather tokyo、AAPL stock
日期计算
3 weeks from today
App 启动器
打前 2-3 字母回车，比点 Launchpad 快 5 倍
系统设置直达
输入 "Display"、"Network" 跳转对应设置面板
建议：如果你重度使用键盘启动器，可以考虑 Raycast 或 Alfred，扩展能力远超 Spotlight（剪贴板历史、窗口管理、自定义脚本、Snippet 等）。Raycast 免费且现代化，推荐替换 Spotlight。

3窗口与桌面管理

macOS Sonoma 之后内建窗口吸附（Window Tiling），Sequoia 进一步强化。

原生窗口吸附（macOS Sequoia+）

  • 拖动窗口到屏幕边缘，会出现吸附预览
  • ⌃+fn+方向键 = 移动到屏幕一半 / 角落
  • Window 菜单 → Move & Resize，有完整选项菜单

Spaces（多桌面）

  • ⌃+↑ 进入 Mission Control，顶部拖拽新建桌面
  • 设置中关掉 "Automatically rearrange Spaces based on most recent use"，保持桌面顺序固定
  • 给每个 Space 绑定不同壁纸，视觉上区分场景
  • 右键 Dock 中的 App → Options → Assign to All Desktops / This Desktop，固定 App 在某桌面

第三方窗口管理（高阶）

如果原生不够用，推荐其中之一：

  • Rectangle（开源免费）：⌃+⌥+方向键 = 左半、右半、最大化、四角等
  • AeroSpace（开源）：i3 风格平铺式窗口管理器，键盘流首选
  • Raycast Window Management：集成在 Raycast 内

4截图与录屏技巧

截图后的操作

  • 截图完成右下角会显示 缩略图，点击可直接标注、裁剪、分享
  • 拖动缩略图到 App / Finder，等于「不存到桌面，直接贴过去」
  • 缩略图弹出期间右键，可改保存位置

截图面板设置（⌘⇧5）

  • Options → Save to：默认改成专门文件夹，避免桌面爆炸
  • Show Floating Thumbnail：关闭后截图直接落盘，不再弹缩略图
  • Show Mouse Pointer：录屏时显示鼠标

修改默认截图位置与格式（命令行）

# 改保存位置
defaults write com.apple.screencapture location ~/Pictures/Screenshots
killall SystemUIServer

# 改格式 (png / jpg / pdf / tiff)
defaults write com.apple.screencapture type jpg

# 截图文件名前缀
defaults write com.apple.screencapture name "shot"

# 去掉截图阴影（窗口截图）
defaults write com.apple.screencapture disable-shadow -bool true
killall SystemUIServer

系统录屏

⌘+⇧+5 → 选择 "Record Entire Screen" 或 "Record Selected Portion"。可同时录系统音 + 麦克风。

专业录屏推荐：免费用 OBS（多源混合）；快速 GIF 录制用 Kap（开源）或 Gifski。

5Finder 效率技巧

必开设置

  • Settings → Advanced → Show all filename extensions：显示后缀
  • Show Path Bar / Status Bar：底部显示完整路径与剩余空间（菜单 View 中开启）
  • Show Library Folder：在 Home 文件夹按 ⌘+J，勾选显示 ~/Library
  • 关闭 iCloud Desktop（如果你不需要桌面同步）

键盘操作

SpaceQuick Look：预览任何文件，无需打开 App
⌘+↓打开文件夹 / 文件
⌘+↑返回上一级
⌘+⇧+G跳转到路径（支持粘贴）
⌘+⇧+.显示/隐藏隐藏文件
⌘+I查看详细信息 (Get Info)
⌘+⌥+V剪切粘贴（先 ⌘C，再到目标按这个）
⌘+⌥+P切换 Path Bar

Quick Look 增强

装这些 QL 插件让 Space 预览能识别更多格式：

brew install --cask qlmarkdown qlstephen quicklook-json
brew install --cask qlcolorcode qlimagesize
  • qlmarkdown：渲染 Markdown
  • qlstephen：预览没有后缀的文本文件 (README, Makefile)
  • qlcolorcode：代码语法高亮

Smart Folders（智能文件夹）

File → New Smart Folder，可以保存搜索条件，比如"过去 7 天修改的 PDF"作为虚拟文件夹。

6终端与 Shell（开发者重点）

终端 App 选择

  • iTerm2：经典之选，分屏、热键终端、配置丰富。brew install --cask iterm2
  • Warp：现代化、命令补全强、AI 集成（部分功能要登录）
  • Ghostty：新兴 GPU 加速终端，性能极佳，配置纯文本
  • WezTerm：跨平台，Lua 配置，平铺式

Shell 配置（zsh 默认）

# 安装 Oh My Zsh（最流行框架）
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# 推荐插件（写到 ~/.zshrc 的 plugins= 内）
#   git zsh-autosuggestions zsh-syntax-highlighting z

# 安装两个最有用的插件
brew install zsh-autosuggestions zsh-syntax-highlighting

或者用更现代的 Starship（跨 shell 提示符，Rust 写的，秒级响应）：

brew install starship
echo 'eval "$(starship init zsh)"' >> ~/.zshrc

7开发环境配置

第一步：Xcode Command Line Tools

xcode-select --install

提供 git、clang、make 等基本工具，所有开发的前置依赖。

Homebrew（包管理器）

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Apple Silicon 装在 /opt/homebrew，Intel 装在 /usr/local。

Brewfile（推荐）：把所有依赖写到 ~/Brewfile，新机器一行恢复：brew bundle。版本控制友好。
# 示例 Brewfile
tap "homebrew/cask"
brew "git"
brew "node"
brew "python@3.12"
brew "ripgrep"
cask "visual-studio-code"
cask "iterm2"
cask "raycast"

版本管理工具（强烈推荐）

  • mise（推荐，Rust 写的，asdf 替代品）：统管 Node / Python / Ruby / Go 等多语言版本
  • nvm / fnm：仅 Node.js
  • pyenv：仅 Python
  • rustup：Rust（官方推荐）
# mise 示例
brew install mise
mise use --global node@20 python@3.12
echo 'eval "$(mise activate zsh)"' >> ~/.zshrc

Git 配置最佳实践

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
git config --global pull.rebase true
git config --global core.editor "code --wait"
git config --global core.autocrlf input

# 启用 delta 美化 diff
git config --global core.pager "delta"
git config --global interactive.diffFilter "delta --color-only"

SSH key（GitHub）

ssh-keygen -t ed25519 -C "you@example.com"
pbcopy < ~/.ssh/id_ed25519.pub  # 已复制公钥
# 粘贴到 https://github.com/settings/keys

Docker / 容器化

  • OrbStack（推荐）：比 Docker Desktop 启动快、省电、轻量，原生 ARM
  • Colima：开源命令行替代
  • Docker Desktop：官方，功能全

8隐藏功能 · defaults write

macOS 大量设置藏在 defaults 命令背后，下面是常用的几条。修改后通常需要 killall <App> 才生效。

Dock

# Dock 自动隐藏时延迟 = 0、动画时间 = 0（响应飞快）
defaults write com.apple.dock autohide-delay -float 0
defaults write com.apple.dock autohide-time-modifier -float 0
killall Dock

# Dock 只显示当前打开的 App（极简）
defaults write com.apple.dock static-only -bool true && killall Dock

# 显示隐藏 App 的图标半透明
defaults write com.apple.dock showhidden -bool true && killall Dock

# 还原
defaults delete com.apple.dock static-only && killall Dock

Finder

# 显示完整路径在标题栏
defaults write com.apple.finder _FXShowPosixPathInTitle -bool true

# 默认显示为列表视图
defaults write com.apple.finder FXPreferredViewStyle Nlsv

# 禁止 .DS_Store 写入网络/U盘
defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool true
defaults write com.apple.desktopservices DSDontWriteUSBStores -bool true

killall Finder

键盘 / 重复速度

# 按键重复速度（越小越快，默认 2）
defaults write -g KeyRepeat -int 2
defaults write -g InitialKeyRepeat -int 15  # 默认 25

# 启用长按键不弹音标菜单，改为重复键入
defaults write -g ApplePressAndHoldEnabled -bool false
注意：键盘设置改完要 注销重登才生效。

其他

# 关闭"启动声"
sudo nvram StartupMute=%01

# 截图改为 jpg（默认 png）
defaults write com.apple.screencapture type jpg

# 显示 ~/Library 文件夹
chflags nohidden ~/Library

# 关闭打开新文件时的"是否要打开?"提示
defaults write com.apple.LaunchServices LSQuarantine -bool false

9输入法与剪贴板

剪贴板历史（系统不自带）

原生剪贴板只有一个槽位，强烈推荐安装：

  • Raycast → Clipboard History（推荐，免费、搜索强）
  • Maccy（开源轻量，brew install --cask maccy）
  • Paste（付费，颜值高）

文本替换（Text Replacement）

系统设置 → Keyboard → Text Replacements。常用片段：

  • ;em → 你的邮箱
  • ;addr → 你的地址
  • ;phone → 手机号
  • ;date → 配合输入法可输入当前日期

iCloud 同步后，iPhone/iPad 上也能用。

输入法（中文）

  • 系统拼音：基础够用，可加自定义短语
  • RIME (鼠须管 Squirrel)：开源、可深度定制、隐私好
  • 搜狗：词库强但有隐私争议

Emoji 与符号面板

任何输入框按 ⌃+⌘+Space 调出 Emoji/符号选择器，含希腊字母、箭头、数学符号等。

10系统维护与性能

查看资源占用

  • Activity Monitor（应用程序 → 实用工具）：CPU / 内存 / 能耗 / 磁盘 / 网络
  • 菜单栏挂件：brew install --cask stats（开源、可配置）
  • 命令行：top、htop、btop

存储清理

# 查看大文件夹
brew install dust ncdu
dust ~/Downloads
ncdu ~/Library/Caches

# Brew 缓存清理
brew cleanup --prune=all

# Xcode 占用极大，清 DerivedData
rm -rf ~/Library/Developer/Xcode/DerivedData/*
  • System Settings → Storage → Manage：系统自带的清理建议
  • OmniDiskSweeper / GrandPerspective：图形化大文件分析（免费）
  • AppCleaner：卸载 App 时连带删除其残留文件

安全与权限

System Settings → Privacy & Security：

  • Full Disk Access：备份/搜索工具需要
  • Accessibility：窗口管理、键鼠工具需要
  • Screen Recording：录屏、远程协助
  • Input Monitoring：键盘 hook 工具
提示：新装 App 第一次运行时若卡住或没反应，先去 Privacy & Security 看是否被拦截。

系统更新策略

  • 主版本（如 14 → 15）建议等 X.1 或 X.2 再升，初版常有兼容性问题
  • 开发机器更新前确认：Xcode、Docker、依赖工具是否已适配
  • Time Machine 备份 + APFS Snapshot，升级前必做

12网络与调试

查看 IP / 网络状态

# 局域网 IP（Wi-Fi）
ipconfig getifaddr en0

# 公网 IP
curl ifconfig.me

# Wi-Fi 信号详情（含信道、强度、噪声）
# 按住 Option 点击菜单栏 Wi-Fi 图标

# 命令行扫 Wi-Fi
/System/Library/PrivateFrameworks/Apple80211.framework/Versions/Current/Resources/airport -s

端口占用排查

# 找谁占着 3000 端口
lsof -i :3000

# 一次性 kill
lsof -ti:3000 | xargs kill -9

DNS 与 hosts

# 刷 DNS 缓存（开发常用）
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder

# 修改 hosts
sudo vim /etc/hosts

抓包与 mock

  • Proxyman / Charles：HTTPS 抓包，需要装根证书并信任
  • mitmproxy：命令行/Python 脚本
  • ngrok / Cloudflare Tunnel：把本地服务暴露到公网

本地静态服务

# Python 自带（无 reload）
python3 -m http.server 8080

# Node 现代化（自动 reload）
npx serve .
npx http-server -p 8080

13Apple 生态联动（容易被忽略）

  • Universal Clipboard：Mac/iPhone/iPad 之间复制粘贴（同 Apple ID + Wi-Fi + 蓝牙）
  • Continuity Camera：iPhone 当 Mac 摄像头/扫描仪，FaceTime/Zoom 直接选
  • iPhone Mirroring（Sequoia+）：Mac 上直接操作 iPhone
  • Handoff：Safari/Pages/Notes 等切设备无缝续
  • Sidecar：iPad 当 Mac 第二屏（有线/无线）
  • AirDrop：跨设备秒传，文件大也行
  • iMessage 接力：Mac 收发 SMS
  • Focus Mode 跨设备同步：一处设置，所有设备应用
iCloud Keychain：系统级密码管理器，Safari 自动填充。如果你不想用第三方（1Password），它已经够好用，且免费。
