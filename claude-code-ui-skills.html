④ UI/UX Pro Max

// 67 风格 + 161 调色板 + 57 字体

nextlevelbuilder/ui-ux-pro-max-skill 71k★

↗ Repo

据称社区最受欢迎的设计 skill。不是简单的提示模板，而是一个推理引擎——分析你的项目类型，自动选择风格 + 调色板 + 字体组合，输出完整设计系统。

UI 风格67 种
调色板161 个（按行业匹配）
字体组合57 套（含 Google Fonts）
推理规则161 条行业规则
支持平台15 个（React / Next / Vue / SwiftUI / Flutter ...）
使用方式（CLI 安装）
1. 全局安装
npm install -g uipro-cli
2. 注入到 Claude
uipro init --ai claude
3. 自然语言驱动
"为我的 SaaS 产品建立 landing page" → 自动生成完整设计系统 + 代码

⑤ Vercel Web Design Guidelines

// 不生成 · 只审计

Vercel Web Design Guidelines AUDITOR

↗ 在 awesome list 中

和上面四个不一样——它不生成 UI，而是用 100+ 条规则审计你（或 Claude）写出来的 UI，覆盖可访问性、性能、UX 一致性。Vercel 工程团队维护，每周 13.3 万次安装。

典型规则类别
Accessibility
对比度、focus ring、ARIA 标签、键盘可达性
Performance
布局抖动、LCP 元素、字体加载、图片尺寸
UX 一致性
触摸目标、loading 状态、错误处理、空状态
跨工具
同时支持 Claude Code / Cursor / Codex / Copilot

怎么选？

// 按场景
你的场景推荐原因
已经在写前端 frontend-design（官方） 已内置 · 自动触发 · 不用额外装
想模仿某个具体品牌 VoltAgent/awesome-claude-design 最直接 · 68 个真实品牌 DESIGN.md，拿来即用
不确定要什么风格 frontend-design-pro-demo 11 种风格有 Live Demo 可看，先挑再用
要一键产出完整设计系统 UI/UX Pro Max 风格+调色+字体组合自动决策，适合从 0 开始
检查 UI 质量 / 可访问性 Vercel Web Design Guidelines 审计而非生成，和上面任一个配合用

个人建议组合： 日常用官方 frontend-design（已内置）+ 需要明确品牌感时拉一份 VoltAgent 的 DESIGN.md 进项目 + 关键页面交付前跑一次 Vercel Guidelines 审计。这三个搭配覆盖 90% 的场景，不需要装 UI/UX Pro Max 那种重型工具。
