Agent View

一个仪表盘，管理所有后台 AI 编程会话

claude --version ≥ 2.1.139 · Pro / Max / Team / Enterprise / API

它解决什么问题

当你同时让 Claude Code 跑多个任务，每个会话占一个终端窗口，状态混乱、来回切窗、容易忘记哪个在等你回复。Agent View 把这些会话收拢到一个面板里。

✕ 没有 Agent View


$ claude refactor...
...running

$ claude tests...
waiting?

$ claude bug fix
...done??

$ claude docs
???

4 个独立终端，无法一眼看出哪个完成、哪个卡住。

➜

✓ 使用 Agent View

● refactor-auth · running
● add-tests · waiting for you
● fix-bug-123 · done
● write-docs · running

所有会话一览无余，状态、最近响应、时间一目了然。

核心效果

Agent View 不只是一个列表视图，它把异步开发流真正变得可用。

统一视图

所有会话集中在一个面板，按 运行中 / 等待你 / 已完成 区分。

异步开发

关掉 Agent View，会话依然在后台跑。你可以做别的事，回来继续。

Inline 回复

Agent 暂停等决策时，在面板里直接回答，它就会继续。无需切回会话。

多任务并行

同时跑多个 feature/重构/修 bug，把 Claude Code 当成一个工程师团队来用。

怎么用

五步即可上手，所有命令都在 Claude Code CLI 里完成。

1

检查版本（≥ 2.1.139）

Agent View 是新功能，旧版本没有。

~/projects/myapp
$ claude --version
claude-code 2.1.139
2

打开 Agent View

在终端运行 claude agents，或在活动会话中按左箭头。

~/projects/myapp
$ claude agents
Opening agent view...
3

把当前会话转入后台

在交互会话中输入 /bg，让它继续在后台干活。

claude · session
claude> /bg
Session moved to background. Use claude agents to view.
4

直接启动一个后台任务

不进入交互界面，一行命令丢给 Claude 让它后台执行。

~/projects/myapp
$ claude --bg "重构 auth 中间件，统一错误处理"
Started background session: refactor-auth-1a2b
5

在仪表盘里管理所有会话

下方就是 Agent View 的实际界面示意 ↓

仪表盘界面示意

三个会话分别处于运行 / 等待 / 完成状态，可以直接在面板里回复"等待你"的那一个。

注意事项

Research Preview 阶段，有几个坑要先知道。

⚠

额度消耗按会话数累加

后台会话和交互会话一样消耗订阅配额。同时跑 10 个 agent ≈ 10 倍速度消耗你的额度。

⚠

会话本地运行

后台会话跑在你的机器上，不是云端。机器睡眠 / 关机 / 网络断开都会中止会话。长任务请注意电源管理。

⚠

Research Preview

API 与命令可能在未来版本变动，不建议在生产脚本中硬编码依赖当前命令格式。
