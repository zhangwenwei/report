1项目是什么

Claude-Code-Game-Studios 是 GitHub 用户 Donchitos 开源的一套 Claude Code 配置模板，把"和 AI 写游戏"从随机的对话式开发，升级为带组织结构的工作室协作。

它的核心思路是：游戏开发其实是一个跨学科协作的工程（策划/程序/美术/音频/QA/制作人），单一 AI 助手很容易在某个领域走偏。所以它把单个 Claude Code session 拆成 49 个有明确职责边界的 subagent，再用 73 个 slash skill 串联完整研发流水线——从概念头脑风暴一直到发布检查。

核心原则一句话：「User-driven collaboration, not autonomous execution.」——Agent 不会擅自动作，而是 提问 → 给选项 → 等决策 → 出草稿 → 等批准。

2Agent 组织架构

系统模拟了真实游戏工作室的三层结构：

Tier 1
导演层
Creative Director / Technical Director / Producer
守护项目愿景、技术底线和进度统筹。跨部门冲突通过 Producer 协调。
Tier 2
部门主管
Design Lead / Programming Lead / Art Lead / Audio Lead / Narrative Lead / QA Lead
各自负责领域的标准与质量，向上汇报、向下分派任务。
Tier 3
专家执行
引擎专家（Godot 4 / Unity DOTS / UE5 GAS）、Shader / VFX / 网络同步 / UI Toolkit / 关卡设计师 / 系统设计师 / 测试工程师等具体岗位。

协作约束

  • 垂直委派：导演 → 主管 → 专家，越级要走流程
  • 横向协商：同层级 Agent 可平等协商，跨部门改动必须经过 Producer
  • 领域边界：Agent 不能擅自修改自己职责外的文件
  • 写文件前必问："May I write this to [filepath]?"

这些案例的共性

  • 零依赖 / 零框架是主流：HTML5 Canvas + 原生 JS + Web Audio API 三件套就能撑起完整玩法
  • 规模可控：从 600 行小游戏到 15000 行重度向，Claude Code 都能 hold 得住
  • 音效用 Web Audio 程序化合成，可以完全跳过资源管线，开发周期从天计而非周计
  • 单文件 / 静态部署极常见，Vercel / Cloudflare Pages / itch.io 直接上线

8适合谁 / 不适合谁

✅ 适合

  • 独立开发者 / 2–4 人小团队，希望"AI 当成员工"做游戏
  • 项目体量在 小到中型（街机、Roguelike、平台跳跃、生存原型、复古射击）
  • 想要 有组织 而不是 放飞 的 AI 协作流程
  • 用 Godot 4 / Unity / UE5 中的任一引擎

⚠️ 谨慎使用

  • 大型 3A 项目（49 个 Agent 仍然只是单 session 内的角色分工，无法替代真实团队）
  • 已经有非常成熟自研工作流的团队（迁移成本可能高于收益）
  • 需要"无人值守自动开发"的场景（这个框架刻意要求人工批准每一步）
